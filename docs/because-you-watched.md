# Because You Watched — staged user-scoped data

`GET /Rowan/Home/BecauseYouWatched` has no caller-specified user, seed, parent or limit. It requires an existing Jellyfin user claim, `HomeEnabled` and independently default-off `BecauseYouWatchedRowEnabled`. Disabled returns `[]`; enabled returns `private, no-store` rows `{SeedId, Seed, Heading, Items}`. Each seed has its own heading and DTO/card identities. `BecauseYouWatchedHideWatched` defaults off and hides watched **results**, not the played seed. No Seerr/Arr input or plugin-level cross-user cache is used.

HSS 3.0.2 `d9798e410cacd4b8fbac4f57fcf3d5c05dd42dbd` uses `BecauseYouWatchedSection.CreateInstances` to take 15 played movies per eligible movie library, shuffle, avoid picking seeds from the same collection and create up to five sections. Its `GetResults` calls the 12.x helper's `ISimilarItemsManager.GetSimilarItemsAsync(seed, [], user, dtoOptions, null, null, cancellationToken)` then optionally filters watched cards and takes 16. HSS's anonymous/null-user and missing-parent fallback are **not** carried over.

Jellyfin 12.1 `ee91c75e777da41a9c4f4855e70adc604fbf2ef8` `ISimilarItemsManager` accepts seed, excluded artist IDs, user, DTO options, candidate limit, library options and cancellation. With `libraryOptions=null`, its manager enables local providers but not remote providers; provider results are not proof of entitlement. The manager's own library-access filtering returns candidates unchanged when its computed accessible-root set is empty. This route therefore filters each seed and result by a current visible top-level movie/mixed collection folder, item standalone visibility and intermediate parent standalone visibility before DTO conversion. It rechecks top-level folders and played seed status after each similar query, then makes a final pass over **every** converted seed and card immediately before responding; revoked cards and empty rows are dropped. Cancellation is checked across provider boundaries and again after final validation (including zero rows), even if a provider ignores the token. A revocation concurrent with or after the final pass cannot be made atomic with HTTP serialization. It caps seed queries to eight libraries × eight pages × 15, results to five seed calls × 64 candidate items (then 16 cards), and collection membership enumeration to 33 per seed (more than 32 rejects that seed). These caps may underfill. Seed order follows played-date query order rather than HSS's shuffle; recommendations preserve manager ranking. The route does not expose remote catalog results or transform native Home/HSS markup.

Unit coverage: disjoint library sets, restricted parent simulation, same-collection seed avoidance, missing-library short circuit, bounded filtered-page refill, result order/watched veto, userless claim. Admin smoke covers independently saved flags and deferred-save mismatch. `python tests/disposable-because-you-watched.py` is a repeatable disposable Jellyfin 12.1 HTTP probe: it builds the Release DLL, provisions two disjoint movie libraries and users with local NFO genre/studio matches, marks one seed per user played, rates a separate containing folder R while its child stays unrated, and enables both default-off flags only in a throwaway config. It asserts a real local-similar recommendation for each seed, seed-specific heading, own-only cards, restricted child exclusion, watched-result hiding after another play mark, `private, no-store`, anonymous 401 and userless-key 403. The disposable probe returned one seed and one matching recommendation per user, with no cross-user result; after the matching card is marked watched, its now-empty row may be absent. The current branch passed 303 .NET tests, 126 Node tests and a Release build. The fixture does not prove that the provider *offered* the restricted child before filtering (although Jellyfin `/Items/{id}` returned 404 for the restricted parent and child), nor browser Home rendering or HSS visual parity. Leave the production gate off; host File Transformation pins remain unset. No live deployment.
