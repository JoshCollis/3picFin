# User-scoped title details (Seerr 3.4.1 / Jellyfin 12.1)

`GET /3picFin/TitleDetails?mediaType=movie|tv&mediaId=<positive TMDb ID>` requires one authenticated, existing `Jellyfin-UserId` claim. It performs one fresh Seerr user mapping and one mapped Seerr detail GET (`X-API-User`) under a shared ten-second deadline, bounded response bytes, and no catalog fetch. Errors return 403 (unmapped) or 502 (invalid/unavailable upstream), not upstream JSON. Responses are `private, no-store`.

The explicit PascalCase DTO is `Title`, `Overview`, `PosterPath` (safe relative poster path or null), `MediaType`, `TmdbId`, `MediaStatus` (Seerr's state, **not** proof of local playback), `LibraryItemId` (nullable GUID), `CanRequest`, `CanRequest4k`, `Seasons` (positive bounded TV season numbers), and `Date` (validated ISO calendar date or null). Request booleans describe the mapped user's Seerr permission and blocklist state independently of local playback: a local series may still lack requestable seasons. Seerr may reject already-requested or available variants. No paths, tokens, Seerr user details, or raw upstream object are returned.

`mediaInfo.jellyfinMediaId` is a hint only. The local resolver scans at most eight currently visible collection roots and 256 candidates per root (the 257th fails closed), with a type-specific user query. It independently requires exact TMDb provider ID and Movie/Series type, a unique match, nonvirtual item, standalone visibility of the item and every intermediate ancestor, and ancestry within the visible root. Before returning an ID, it re-reads the user's root membership and standalone visibility of the root, item, and every intermediate ancestor, along with the item's type, provider ID, and ancestry; a revocation during the scan fails closed. A supplied hint must agree with the verified match; malformed hints are ignored. Missing, ambiguous, over-budget, inaccessible, or mismatched matches yield `LibraryItemId: null`. The UI must navigate only when that ID is non-null; Seerr's `MediaStatus: 5` alone must never imply playback.

The bounded scan trades false negatives in large libraries for safe uniqueness. The automated tests use injected user/resolver seams and pure policy inputs; they do not prove HTTP routing or a live two-user Jellyfin database, which remains an integration verification gap.
