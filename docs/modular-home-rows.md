# Modular native Home rows (staged)

`RowanNativeHomeRows.createRows({ document, IntersectionObserver, enabledRows, openItem })` mounts only in a caller-owned container with `mount(root, ApiClient, userId)`; `dispose()` removes all rows, disconnects observation and invalidates pending work and card actions. Load `3picFin/Web/native-home-rows.css` explicitly alongside the JS when mounting. No production injection or HSS `.sections` mutation is added: `HomeAdapterRegistration.VerifiedIndexSha256`, `home-adapter.js`'s distribution pin and `home-tab-host.js`'s bundle pin remain null. The host must attest its exact active web response, verify the current signed-in user and route, and call dispose synchronously on logout/route exit. An `openItem` callback is trusted-host navigation only; without it Jellyfin cards are noninteractive. No playable action is ever offered for Seerr candidates.

Opt in each name separately: `BecauseYouWatched` calls `Rowan/Home/BecauseYouWatched` once when visible, validates at most five seed rows with up to 16 items each, and renders each seed as a separate vertical section with its own heading and horizontal landscape-card strip preserving movie item identities. `Discover`, `DiscoverMovies` and `DiscoverTV` each call their own `3picFin/HomeDiscover/{name}` endpoint when visible, validate up to 20 candidate DTOs, and show portrait cards with explicit Seerr candidate labeling and only allowlisted TMDb poster URLs. Candidate DTOs have TMDb identity, not Jellyfin playback identity; the feed does not prove whether a title is already in the library. Error responses and malformed oversized lists fail closed; no automatic pagination or request submission is attempted. API flags remain independently default-off on the server. This UI is a staged preview, not HSS UX parity or a live browser deployment.
