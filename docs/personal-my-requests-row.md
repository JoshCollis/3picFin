# Personal My Requests Home data (staged)

HSS 3.0.2 (`d9798e4`, `MyRequestsSection.cs`) reads the current user's Seerr requests, selects `media.jellyfinMediaId`, queries permitted Jellyfin libraries, optionally hides watched items, sorts by Jellyfin `DateCreated`, and takes 16. It is **not** the global household request-history list. This slice uses Seerr's Jellyfin-GUID mapping with a fresh mapped ID, `X-API-User`, `requestedBy`, and a response requester-ID check instead of HSS's username lookup. It accepts approved/completed requests with available/partially-available media status and a nonempty valid local item GUID; missing/malformed statuses fail closed. The first 100 personal request results are inspected, not an unbounded history scan.

`GET Rowan/Home/Rows/MyRequests` requires an authenticated existing Jellyfin user, Home and independent `MyRequestsRowEnabled` opt-in (default off). It intersects resolved items with up to 64 currently visible collection folders, checks `IsVisibleStandalone(user)` before DTO conversion, optionally excludes played items via `MyRequestsHideWatched`, deduplicates and returns 16 newest `DateCreated` items. Empty IDs never produce an unrestricted query. Both flags are independent of `SharedRequestsEnabled` and request POSTs. Failures are sanitized, with `private, no-store` responses. The standalone `native-home-rows.js` renderer requests this row lazily only if its caller passes `enabledRows: ['MyRequests']`; it does not inject itself automatically into Home or modify HSS.

Limitations: only the first 100 Seerr requests are inspected, so older requests can be omitted. A Seerr response lacking `requestedBy.id` is treated as unavailable rather than assumed personal. This slice has policy, transport, configuration and Node tests plus Release build, but not a populated disposable Jellyfin/Seerr HTTP or browser parity run. Production Home bundle pins remain unset; no live deployment has been made. Keep HSS active until populated two-user, parental visibility, navigation and presentation checks pass.
