# Independent Home hero mode

`HomeEnabled` and `HeroTrustedFilesystemEnabled` must be on, with a nonempty, valid explicit `HeroLibraryIds` selection. `DiscoveryPageEnabled` may be turned off for hero-only Home. The portable adapter checks the Jellyfin 12.1 runtime, Home script timing, native DOM, active route and signed-in user instead of requiring distribution-specific pins. The filesystem-writer trust decision and metadata image-route confinement remain mandatory. Neither the mode response nor web assets contain credentials or library inventory.

The signed-in, no-store `GET Rowan/Home/Mode` returns only `DiscoveryEnabled` and `HeroEnabled`. On a verified Home mount the host reads this mode before loading a fragment. With Discovery off it leaves native HSS sections in place, adds no 3pic Fin tab or Discovery HTML/JS/CSS, and mounts the hero above the sections only if the user-scoped slide route returns valid slides. With Discovery on it retains the Home/3pic Fin inner switch and defers Discovery data until selected. Favorites and native route ownership remain Jellyfin's. Route exit, logout, and identity switch tear down the host, hero blobs and styles; a remount reads the mode again.

The image endpoint still applies its own user, selected-root, ancestor-visibility, trusted-filesystem and confined metadata-file checks. The mode flag is a UI hint, never authorization for image retrieval. Existing saved feature settings are respected; new installations enable Home and Discovery, not image trust or shared household feeds.

Automated coverage includes .NET flag/asset-gate tests, Node lifecycle tests, a signed-in stock Jellyfin 12.1 disposable browser, and an unchanged-public-DLL clone of a customized web distribution. The customized clone passed direct 390, 768 and 1100px Discovery/Home/Fin/HSS/Favorites/logout/second-user and metadata-JPEG hero/Open checks; hero-only passed at 390px with anonymous and userless requests denied. Direct 320px exposed an HSS card overflow, and strict `/jellyfin/` proxy cases returned 404 for root-absolute HSS/Plugin Pages assets (3pic Fin's own paths stayed prefixed). ElegantFin and live household parity remain unverified. Configuration changes on an already mounted Home route take effect on remount.
