Empty selection shows no slides. Up to 10 still images from the signed-in user’s visible items; Home and trusted metadata must also be enabled.

Privacy and safety details

Default off. Requires Home enabled. Hero images are confined to Jellyfin's internal metadata library root, not media/share paths. On supported Linux, the image file is opened atomically within that root; symlinks and nested mounts are rejected. Only enable after auditing metadata ownership and write access: malicious writers inside the metadata filesystem can still create hardlinks or change file contents in place. Keep off on a live server until its metadata trust and image behavior are verified. Jellyfin's separate raw image API may still serve images anonymously by item ID.

Requests
Privacy and safety details

Requires Home and Seerr for Home feeds. Candidate titles are not Jellyfin library items or playable claims. Seerr discovery can reveal non-adult titles outside each user's Jellyfin libraries and parental visibility. All signed-in Jellyfin users can see household request statuses, including titles outside their library; anonymous users and userless API keys cannot. Only the signed-in user's mapped requests with locally available, currently visible Jellyfin media are returned in Personal My Requests. Seerr permissions still govern request creation.

Arr & household activity

Leave API keys blank to retain saved keys. Calendar and Downloads are independent; upcoming rows require Home and Calendar.

Privacy and safety details

Every existing signed-in Jellyfin user can see upcoming Radarr movie releases and Sonarr episode titles/dates, including titles outside their libraries or parental restrictions. Downloads expose queue titles including titles outside their libraries or parental restrictions. Upcoming rows expose monitored no-file Arr titles including titles outside their Jellyfin libraries or parental restrictions. These are candidates, not playable Jellyfin items; activity does not establish request ownership, file presence, or Jellyfin watchability. Never enable if household-wide disclosure is unsuitable. API keys remain server-side; configure trusted Arr URLs only.
